# 工艺决策采集表

工艺专业判断由工程师提供；系统方负责提问、记录，并把经验写成可执行规则。

| 编号 | 主题 | 要问工程师的问题 | 当前规则（可在软件里改） | 启用 |
| --- | --- | --- | --- | --- |
| blank-thickness | 毛坯 | 什么时候用板材，什么时候用块料？ | 厚度不超过 30 mm、外形接近矩形用板材；更厚或六面加工用块料 | 是 |
| blank-round | 毛坯 | 什么时候用圆钢下料？ | 回转体才用圆钢，底板/压板一般不用 | 是 |
| seq-datum | 工序 | 第一道切削为什么先铣基准？ | 毛坯基准未加工时，先铣大面和相邻侧面 | 是 |
| seq-hole | 工序 | 高精度孔怎么拆工序？ | H7/H8 配合孔按钻→扩（可选）→铰 | 是 |
| seq-slot-after-hole | 工序 | 开口、腰槽和孔谁先谁后？ | 有位置关系时先孔后开口 | 是 |
| fix-batch | 装夹 | 什么时候上专用夹具？ | 批量 ≥ 50 或外形不规则 | 是 |
| fix-general | 装夹 | 什么时候通用装夹就够？ | 小批量、外形规矩的底板和压板 | 是 |

采集时每个案例尽量备齐：最终版 CAD、实际工艺路线（工艺卡 / 口头说明）、若有则附 CAM 或关键工序说明。本阶段不需要全量数据。
