# 项目起步阶段实施说明

（模块二：制造工艺规划与自动化加工支撑模块 CAPP）

## 一、当前阶段的工作范围与定位

本阶段只做模块二：制造工艺规划与自动化加工支撑（CAPP），暂不开展模块一（结构特征自动生成）。

原因：

- 制造工艺是后续自动化与设计生成的基础
- 工艺逻辑未稳定时，结构自动生成没有可加工性保障
- 按工程顺序应先固化「如何加工」，再讨论「如何设计」

本阶段目标：把成熟的工艺决策逻辑，变成可执行、可复用的工艺自动生成能力。

## 二、起步阶段总体目标

唯一目标：在工程师给出的工艺决策规则基础上，系统能否自动生成「工程师认可的工艺路线」。

不以模型指标为目标，以工程可接受度为唯一评判标准。

## 三、实施步骤

1. **试点零件范围**：1–2 类最典型夹具零件，每类约 5 个已完成案例（本仓库已放入底板类、压板类各 5 件）。
2. **工艺决策逻辑采集**：毛坯选择、工序拆分与顺序、装夹（通用 / 专用）。见同目录《工艺决策采集表》。
3. **规则化与原型验证**：自动输出工序顺序、毛坯建议、装夹方式；工程师标「可接受 / 需调整」。
4. **效果评估**：自动路线是否符合工程逻辑、人工修改量是否下降、是否具备扩展基础。
