# 预检机

预检机（预调 + 测量）仿真工作站：零件装在零点托盘上，测头自动找基准，建立新的加工坐标系并改写加工程序；加工后回到预检机测量尺寸和形位公差。

当前是纯软件仿真，不连接真实运动控制卡、测头和相机。上一阶段的 CAPP 工艺规划原型保留在 `/capp`，暂停迭代。纸面材料在 [`docs/`](./docs/) 目录。

## 预检流程（仿真）

1. **回零**：上电或急停后必须先回零，否则禁止自动运行。
2. **建固定坐标系**：测托盘上的 Ø10 标准球。同一截面 4 点，径向逼近、径向退出，点间绕球心走 90° 圆弧，最后测顶点。没有固定坐标系不允许测量找正；平时可在坐标系页「复核漂移」，超过 2 μm 要重建。
3. **一键预调**：没有固定坐标系时先建立，再按布点规则自动编程、自动测量、3-2-1 自动找正，输出工件坐标系。也可以在程序面板选「预调」「复测」自动生成程序后手动运行，或「导出 DMIS」交给现成三坐标软件采点。千分表找正在运动面板。
4. **坐标系**页：零件相对零点托盘的偏差，换算成 G54~G59。可填零件温度，尺寸按 20 °C 换算。
5. **加工程序**页：只输出坐标系偏置，或按实测装夹改写整个程序。必须看过刀路才能导出。
6. **复测**：加工后再上预检机，选「复测」测孔径、位置和形位公差。报告是过程检查，不能代替鉴定三坐标的证书。
7. 点 **装新零件** 换一个随机装偏的零件。仿真里真实位置软件事先不知道。

## 代码结构

| 目录 | 内容 |
| --- | --- |
| `src/lib/math` | 向量、3×3 矩阵、特征分解、刚体变换 |
| `src/lib/measure` | 平面/直线/圆/球几何拟合，测针半径补偿，形位公差 |
| `src/lib/coords` | 3-2-1 找正、一面两孔找正、托盘偏差、工件坐标系输出 |
| `src/lib/nc` | FANUC 风格 G 代码解析与坐标改写、行程检查 |
| `src/lib/motion` | 运动控制接口、仿真控制器（S 曲线、软限位拒绝、急停后须回零）、真机桩 |
| `src/lib/sim` | 仿真世界（有向距离场），测头触测与路径碰撞预检 |
| `src/lib/program` | 预检程序定义、执行、评价、标准球标定 |

## 上真机前还缺什么

- 本地设备服务：对接运动控制卡、光栅尺、测头触发锁存；急停和硬限位走硬件回路。
- 温度补偿、几何误差补偿表，并用量块、环规验证精度。
- 真实相机标定和手眼标定；STEP 模型导入与选点编程。
- 与 PLC / 机床（写入工件坐标系）/ MES 的接口。
- 形位公差最小区域法评价。

## Windows 克隆到「CMM」文件夹

Origin CLI 只支持 macOS / Linux / WSL。在 WSL 里：

```bash
curl -fsSL https://downloads.cursor.com/origin/install.sh | sh
origin auth login
cd /mnt/c/Users/你的Windows用户名/Desktop
origin repo clone wanghaoran2026/cmm-motion-vision CMM
cd CMM
npm install
npm run dev
```

若提示找不到 `origin`：

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```
